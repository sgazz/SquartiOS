# Squart Release Notes v1.0 (Internal)

## Summary
Squart v1.0 delivers a calm, tactical board-game experience centered on space control, directional play, and blocking decisions.

## Key Product Scope
- 2D Board and 3D Board play modes
- Local Player vs Player
- Player vs AI with Easy / Medium / Hard difficulties
- Role and turn-order selection in PvAI
- Deterministic Daily Challenge

## Presentation & UX
- Premium tactical visual direction
- Theme system with free default and premium theme pack
- Alternate app icon infrastructure tied to themes
- Polished in-game HUD, previews, overlays, and interaction flow

## Commerce
- StoreKit 2 integration foundation
- Non-consumable product: `squart.premium`
- Premium Themes & Icons unlocks premium themes and alternate app icons
- Core gameplay remains available without purchase

## Tactical Identity (Core Experience)
- Quiet strategic pacing
- Direction-based placement (Horizontal vs Vertical roles)
- Blocking and denial as primary win condition
- Daily deterministic board variation for repeat play
